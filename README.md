# equatians
A fictional species built from equations.

Эксперимент: организмы, все органы которых — математические функции.
Сейчас реализован абсолютный минимум: у организма один орган — движение.

## Запуск

```bash
sbt run     # окно симулятора
sbt test    # тесты модели
```

Нужны sbt и JDK 17+ (проверено на JDK 25).

Параметры мира (сетка секторов, численность, сид, диапазоны генов, какие виды появляются,
ступени ускорения) — в [`src/main/resources/application.conf`](src/main/resources/application.conf).
Другой файл можно подложить без правки этого: `sbt -Dconfig.file=my.conf run`.

Управление: `Space` — пауза, `+`/`-` — скорость (от 1 до 10 000 тиков за кадр),
`N` — один тик, `R` — новый мир, `T` — следы, клик по организму — его формула.

## Модель

- **Мир** — сетка квадратных секторов (`WorldConfig`), у каждого сектора свои декартовы
  координаты: (0, 0) в левом нижнем углу, y вверх. Переходить между секторами пока нельзя —
  граница сектора работает как стена, от которой организм отражается.
- **Функция** (`MathFunction`) — полином 1–3 степени, логарифм, синусоида или экспонента.
  Семейство функции = вид организма (цвет на экране).
- **Орган движения** (`MovementOrgan`) — «черепашка»: за тик организм делает шаг длины `speed`
  в направлении θ = f(x), где x — фаза цикла: `x = (возраст mod period) / period · span`.
  Поэтому линейная f рисует дуги окружностей, квадратичная — спирали Эйлера, синус — змейку.

## Структура

```
src/main/scala/equatians/
  model/  Vec2, MathFunction, MovementOrgan, Organism, World — чистая модель, без UI
  sim/    Genesis, GenesisConfig — случайное заселение мира
  ui/     Main, WorldView, Formula — Swing-визуализация, формулы через jlatexmath
  AppConfig.scala — чтение application.conf
```
