# equatians
A fictional species built from equations.

Эксперимент: организмы, все органы которых — математические функции.
Сейчас реализован абсолютный минимум: у организма один орган — движение.

## Запуск

```bash
sbt run     # окно симулятора
sbt test    # тесты модели
```

Нужны sbt и JDK 17+ (проверено на JDK 25).

Параметры мира (сетка секторов, численность, сид, диапазоны генов, какие виды появляются,
ступени ускорения) — в [`src/main/resources/application.conf`](src/main/resources/application.conf).
Другой файл можно подложить без правки этого: `sbt -Dconfig.file=my.conf run`.

Управление: `Space` — пауза, `+`/`-` — скорость (от 1 до 10 000 тиков за кадр),
`N` — один тик, `R` — новый мир, `T` — следы, клик по организму — его формула.

## Модель

- **Мир** — сетка квадратных секторов (`WorldConfig`), у каждого сектора свои декартовы
  координаты: (0, 0) в левом нижнем углу, y вверх. Переходить между секторами пока нельзя —
  граница сектора работает как стена, от которой организм отражается. Организм видит только свой сектор.
- **Функция** (`MathFunction`) — константа, полином 1–3 степени, логарифм, синусоида или экспонента.
  Семейство функции движения = вид организма (цвет на экране). Свои своих не атакуют.
- **Орган движения** (`MovementOrgan`) — «черепашка»: за тик организм делает шаг длины `speed`
  в направлении θ = f(x), где x — фаза цикла: `x = (возраст mod period) / period · span`.
- **Орган атаки** (`AttackOrgan`) — одна функция D(u), u = d / max-reach, задаёт всё:
  урон на дистанции d = D(u) · √(макс. здоровье / reference-health); дальность — первый ноль D;
  стоимость удара = cost-factor · ∫D по дальности. Крупный бьёт сильнее, и ранение этого не меняет.
- **Тело и энергия** (`Organism`):
  - максимальное здоровье — весовая категория: радиус r = k·√(макс. здоровье), ранения размер не уменьшают;
  - ёмкость жира пропорциональна максимальному здоровью: крупные запасают больше;
  - рождаются с полным здоровьем и 100% сытостью;
  - пока здоровье не полное, организм лечится: `healing.rate` за тик по `healing.cost` сытости (или жира) за единицу;
  - сытость тратится каждый тик: r · (base + movement-cost · шаг²) — крупным и быстрым дороже;
  - когда сытость на нуле, тратится жир; 1 единица жира = `reserve-density` сытости;
  - когда нет и жира, неоплаченный расход отнимает здоровье — организм умирает от голода.
- **Поведение** (`Simulation`): раз в `decision-interval` тиков организм смотрит на ближайшего чужака
  в радиусе восприятия. Голодный (сытость ниже порога) начинает преследование с вероятностью,
  растущей с голодом; сытый с запасом жира с некоторой вероятностью отдаляется; иначе — обычное движение.
  Раненый решает: отвечать нападающему (та же вероятность охоты) или бежать.
- **Бой и еда**: преследователь бьёт цель в зоне удара раз в `cooldown` тиков, если может оплатить удар.
  Тело погибшего — еда: мясо (`meat-per-health` · макс. здоровье) плюс оставшийся жир, в единицах жира.
  Убитого ест нанёсший наибольший урон: еда по курсу заполняет сытость, излишек идёт в жир.
  Что не влезло — остаётся трупом (падалью), его может доесть любой. Умершие от голода тоже оставляют труп.
- **Падаль**: каждый тик организм, у которого сытость ниже порога, с высокой вероятностью бросает
  погоню или обычное движение и идёт к ближайшему трупу в поле зрения (бегство не прерывается).
- **Размножение**: взрослый (`maturity-age`), сытый, с жиром и здоровьем выше порогов организм после
  перерыва (`cooldown`) ищет такого же готового партнёра своего вида и идёт к нему; при контакте рождается помёт.
  Размер помёта — среднее генов `litter-size` родителей, но детей столько, сколько оба могут оплатить:
  каждый стоит тела (`body-cost-per-health` · его макс. здоровье) плюс сытости, с которой рождается; платят поровну.
- **Гены и мутации** (`Genetics`): функции движения и урона (коэффициенты), период, span, скорость,
  макс. здоровье, размер помёта. Каждый ген — от случайного родителя, затем с вероятностью `mutation.rate`
  нормальный шум. С вероятностью `family-rate` функция меняет семейство — у функции движения это новый вид.
- **Корм** — возобновляемый источник энергии: любой организм с функцией движения-константой θ(x) = c.
  Он медленно ползёт по прямой, не ест, не голодает, не убегает и не дерётся; голодные охотятся на него,
  убивают и съедают тело. Корм размножается делением без партнёра: каждый тик с вероятностью
  `reproduction-rate · (1 − n / max-per-sector)` отпочковывает клона (энергию берёт из среды), так что
  несъеденный корм быстро заполняет сектор. У корма есть «спящие» гены — период, span, функция урона.
  С вероятностью `awakening-rate` функция движения клона меняет семейство, и он **пробуждается**:
  становится активным организмом нового (или уже существующего) вида. Изредка корм появляется и сам
  (`spawn-rate`), чтобы опустевший сектор ожил. Падаль важнее корма, корм важнее охоты на чужаков.
- **Журнал**: каждый организм пишет решения, удары, ранения, еду и смерть — клик по организму
  показывает журнал, в том числе у недавно погибших (на месте гибели рисуется крестик).

Все случайные решения детерминированы: зависят только от сида мира, тика и id организма.

## Структура

```
src/main/scala/equatians/
  model/  Vec2, MathFunction, MovementOrgan, AttackOrgan, Organism, World, Rules — чистая модель, без UI
  sim/    Simulation — правила тика; Genetics — наследование; Genesis — заселение; Forage — корм; Narrative; Rng
  ui/     Main, WorldView, StatBar, Formula — Swing-визуализация, формулы через jlatexmath
  AppConfig.scala — чтение application.conf
```
